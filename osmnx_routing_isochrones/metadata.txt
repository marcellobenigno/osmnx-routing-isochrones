about=Calculate routes and reachability isochrones using OpenStreetMap street network data via OSMnx.
    Four Processing algorithms: download a road network to a GeoPackage, inspect it, compute one-way aware shortest paths (car or pedestrian) and generate isochrones from points or point layers. Routing runs locally on the saved network, with no routing web service or API key.
    Requires the Python library osmnx installed in QGIS's Python (see the homepage for a one-line install). Interface in English, Brazilian Portuguese and Spanish. Data © OpenStreetMap contributors (ODbL).
